# Simulador de Presupuestos y Control de Stock

Este proyecto es una aplicación de consola (CLI) desarrollada en Node.js. Simula las operaciones comerciales de un negocio de ropa, gestionando inventario, facturación básica y aplicación de reglas de negocio de forma modular.
